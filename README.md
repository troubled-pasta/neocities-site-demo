# Age-gated Neocities Site Demo

Neocities already lets you mark a site as 18+ in site Settings, but I made this project for people who want to host NSFW or adult content on Neocities with peace of mind that nobody is seeing it unless they actively choose to.

## Features

- Fully keyboard accessible, including galleries, carousels, and their respective lightbox modals
- Mobile-responsive layout
- Age gate that traps keyboard focus
- `noscript` page with user-friendly instructions
- CSS variables for easy site-wide styling updates
- Bootstrap 12-column grid layout
- Smooth transitions between pages
- UserWay accessibility widget
- Anti-AI `robots.txt` (AI crawlers can also be blocked through Neocities site settings)

### Userway acessibility widget

Userway was originally an Israeli company. It was bought out by an American company in 2023 but it's difficult to say how much of it is still tied to Israel. No money is given to the company by the use of this widget, but if this bothers you, you can delete the userway content from scripts.js. I chose to include it because I believe the level of control and relief it brings to users outweighs the harm of association, but you are welcome to make your own judgement call about its inclusion in your site.

## How to use this repository

If you're not familiar with GitHub, think of it like an online folder where I can store my website files and update them over time without having to upload a new ZIP file every time something changes. Most of the stuff on this page is only relevant to people contributing to the project (i.e. me), but you can check this page to see how long ago the last update was, as well as the distribution license ('rules') for the code itself under `MIT license`.

### Steps to download:

- Click the green `<> Code` button near the top of this page.
- Select `Download ZIP`.
- Extract the ZIP file on your computer.
- Upload the files inside to your Neocities site's root folder.
