# Age-gated Neocities Site Demo

Neocities sites already let you mark a site as 18+ in site Settings, but I made this project for people who want to host NSFW or adult content on Neocities with peace of mind that nobody is seeing it unless they actively choose to.

## Features
- Fully keyboard accessible, including galleries, carousels, and their respective lightbox modals
- Mobile-responsive layout
- Age gate that traps keyboard focus
- `noscript` page with user-friendly instructions
- CSS variables for easy site-wide styling updates
- Bootstrap 12-column grid layout
- Smooth transitions between pages
- UserWay accessibility widget
- Anti-AI `robots.txt` (AI crawlers can also be blocked through Neocities site settings)
