JavaScript required

JavaScript has been detected as disabled in your browser. JavaScript is required for this website to function as intended and to provide a fully accessible experience for people navigating via keyboard.

In particular, JavaScript enables the image galleries to be properly keyboard accessible, allows lightbox galleries to open, close and change slides correctly, ensures that interactive components such as accordions and video controls work as expected, and allows the accessibility widget to function.

This site is intentionally designed to not display content when JavaScript is disabled. Because core functionality relies on JavaScript, showing partial content without it could result in a broken, confusing, or inaccessible experience. Please enable JavaScript to access all features of the site and to use it effectively.

How to enable JavaScript

Enabling JavaScript differs depending on your browser. Below are some examples of how to find where to turn on JavaScript:

  • Chrome - Settings → Privacy and security → Site settings → JavaScript → Allow
  • Firefox - Type about:config in the address bar → search for javascript.enabled → set it to true
  • Safari - Settings → Advanced → Enable JavaScript
  • Edge - Settings → Cookies and site permissions → JavaScript → Allow
  • Opera - Settings → Privacy and security → JavaScript → Sites can use JavaScript

NB: Your specific browser version may have these settings in a different place. If these instructions don't work for you, please web search "Enable Javascript" + [Your browser name] and follow the instructions in the search results.
